
# SCILAB CHANGES REQUIRED FOR RECEIVER-DERIVED TRAINING

The current SmartScan_final_fixed/main.sce has CONFIG_ID_TO_RUN = 0 and the
current ml_observation_live.csv has no config_id or step. For training across
all configurations, add those identifiers to the observation stream. They are
metadata only and are NOT ML features.

1) In ml_interface.sci, change ml_init_interface(base_dir) header to:

mfprintf(fd,"config_id,step,scan_time_s,scan_center_mhz,scan_lower_mhz,scan_upper_mhz,dwell_s,total_pdws,station_hit_count,track_count,rs1_pdws,rs1_mean_snr_db,rs1_mean_aoa_deg,rs2_pdws,rs2_mean_snr_db,rs2_mean_aoa_deg,rs3_pdws,rs3_mean_snr_db,rs3_mean_aoa_deg,mean_frequency_mhz,mean_amplitude_dbm,max_amplitude_dbm,mean_snr_db,max_snr_db,mean_pulse_width_us,mean_aoa_deg,hit\n");

2) Change ml_write_observation signature to:

function ml_write_observation(base_dir,obs,config_id,step)

and prepend config_id and step to its mfprintf row:

mfprintf(fd,"%d,%d,%.9f,%.6f,%.6f,%.6f,%.9f,%d,%d,%d,%d,%.6f,%.6f,%d,%.6f,%.6f,%d,%.6f,%.6f,%.6f,%.6f,%.6f,%.6f,%.6f,%.6f,%.6f,%d\n", ...
    config_id,step, ...
    x.scan_start_s,x.scan_center_mhz,obs.scan_lower_mhz,obs.scan_upper_mhz,x.dwell_s, ...
    x.receiver_pdw_count,x.station_hit_count,x.track_count, ...
    x.rs1_pdws,x.rs1_mean_snr_db,x.rs1_mean_aoa_deg, ...
    x.rs2_pdws,x.rs2_mean_snr_db,x.rs2_mean_aoa_deg, ...
    x.rs3_pdws,x.rs3_mean_snr_db,x.rs3_mean_aoa_deg, ...
    x.mean_frequency_mhz,x.mean_amplitude_dbm,x.max_amplitude_dbm, ...
    x.mean_snr_db,x.max_snr_db,x.mean_pulse_width_us,x.mean_aoa_deg,x.hit);

3) Do the same for ml_write_empty_observation:
function ml_write_empty_observation(base_dir,config_id,step,scan_time_s,center_mhz,lower_mhz,upper_mhz,dwell_s)

and prepend config_id,step to the CSV row.

4) In main.sce change:
ml_write_observation(BASE_DIR,receiver_observation);

to:
ml_write_observation(BASE_DIR,receiver_observation,CONFIG_ID_TO_RUN,scan_number);

For empty scans change the call to:
ml_write_empty_observation(BASE_DIR,CONFIG_ID_TO_RUN,scan_number,scan_start_s,empty_center,empty_lo,empty_hi,irsa_state.scan_dwell_s);

5) For a real all-configuration training run, execute the baseline replay once
per config and APPEND to separate training files, or build a dedicated training
replay that loops over every config_*.h5. Do not concatenate config 0 and config 1
without recording config_id.

IMPORTANT:
The online production CSV can keep the 25-column schema if desired. The
config_id/step columns are for the training/audit stream and are not used as
model features.

Ground truth target generation should be separate from ml_observation_live.csv:
for each config_id + temporal step, write active_0..active_237 where each value
is 1 if the RF environment contains an emitter in that 50-MHz receiver window
during that temporal dwell, else 0. This file is evaluation/training only.
